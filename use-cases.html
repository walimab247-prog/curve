Oracle Use Cases

Real-world and blockchain-native examples of how oracle infrastructure is used. Fact-based, neutral overview.

Decentralized Exchanges

Automated market makers such as Curve use internal and external price references to route trades and to parameterize pools that concentrate liquidity around expected exchange rates.

Source reference: Curve documentation

Lending and Borrowing

Lending protocols use price feeds to value collateral and decide when positions become under-collateralized. Accurate feeds are critical: incorrect values can cause wrongful liquidations.

Source reference: ethereum.org — Oracles

Stablecoins

Collateralized stablecoins, including Curve's crvUSD, rely on price oracles to track collateral value and manage soft-liquidation mechanisms.

Source reference: Curve documentation

Tokenized Real-World Assets

On-chain representations of off-chain assets (such as treasury instruments) need external data about the underlying asset's value and status.

Source reference: ethereum.org — Oracles

Cross-Chain Communication

Bridges and messaging layers use oracle-like validator sets to attest that an event occurred on one chain so a contract on another chain can act on it.

Source reference: ethereum.org — Oracles

Insurance and Derivatives

Parametric on-chain insurance and derivative contracts settle against externally reported outcomes, such as an index level at a given time.

Source reference: ethereum.org — Oracles
